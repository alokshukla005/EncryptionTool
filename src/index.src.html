EncryptionTool

Encrypt any file with a public key and decrypt it with the matching private key. Everything happens in this browser tab. Nothing is uploaded.

1. Public key (RSA .pem or PGP .asc)
2. File to encrypt (any format, up to 10 MB)
1. Private key (RSA .pem or PGP .asc)
2. File to decrypt

With a PGP key (.asc) the output is a standard OpenPGP message, so GnuPG and other PGP tools can decrypt it. With an RSA PEM key, each file is encrypted with a fresh AES-256-GCM key that is locked with your public key (RSA-OAEP, SHA-256), and only this tool decrypts it.

Keep your private key safe. A file cannot be recovered without it.
